# 规则文件格式模板

---

## R-01：空 catch 块（忽略异常）

- **规则ID**：R-01
- **标签**：[缺陷]
- **严重级别**：P1
- **检查项描述**：catch 块中未做任何处理，直接吞掉异常，可能导致问题被隐藏
- **扣分值**：-10

**正面示例**：
```
try {
    // 业务逻辑
} catch (Exception e) {
    logger.error("操作失败", e);
    return defaultValue;
}
```

**反面示例**：
```
try {
    // 业务逻辑
} catch (Exception e) {
    // 什么都没做
}
```

---

## R-02：日志记录敏感信息

- **规则ID**：R-02
- **标签**：[安全]
- **严重级别**：P0
- **检查项描述**：在日志中输出 token、密钥、密码等敏感信息，可能导致信息泄露
- **扣分值**：-25

**正面示例**：
```
logger.info("用户登录成功, userId={}", userId);
```

**反面示例**：
```
logger.info("登录成功, token={}", token);
```

---

## R-03：循环内执行 I/O 或数据库操作

- **规则ID**：R-03
- **标签**：[性能]
- **严重级别**：P1
- **检查项描述**：在循环内部执行文件 I/O、网络请求或数据库操作，导致性能瓶颈
- **扣分值**：-10

**正面示例**：
```
ids = collectAll()
batchProcess(ids)
```

**反面示例**：
```
for item in items:
    db.save(item)      # 循环内频繁操作
```
