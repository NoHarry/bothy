# 领域和 API 陷阱

累积的领域特定陷阱和 API 怪癖知识。
在底部追加新条目。永不删除现有条目。

## 格式

每个条目遵循此结构：
- **日期**：YYYY-MM-DD
- **来源**：这是在哪里发现的（例如：`harness/trace/2026-01-15-user-api.md`）
- **上下文**：正在做什么
- **陷阱**：出了什么问题或令人惊讶的事
- **解决方案**：如何正确处理
