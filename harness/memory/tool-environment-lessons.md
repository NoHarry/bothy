## 格式

- **日期**：YYYY-MM-DD
- **来源**：这是在哪里发现的（例如：`harness/trace/2026-02-01-ci-fix.md`）
- **工具/环境**：什么工具或环境组件
- **经验**：学到了什么
- **变通方法**：如果有的话，如何绕过问题
