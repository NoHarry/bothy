# 问题 — {feature_name}

> 评审中发现的问题、坑和意外发现。仅可追加。
> 本文件不是确认账本；需要人类确认的问题必须进入 `generated/product-spec-review.md` 或 `outputs/product-spec-review.md`。
> 本文件只能记录证据、默认建议和确认入口，不维护 `主确认方/协同确认方/待确认/已确认/签署人` 等确认状态。

## 格式
- **[YYYY-MM-DD] 问题标题**
  - 问题：{发生了什么}
  - 影响：{影响了什么}
  - 证据：{来自 PRD、代码、配置或引用文档的证据}
  - 默认建议：{评审默认建议，或"无"}
  - 确认入口：{product-spec-review.md 中的条目 ID；无需人工确认时写"不需要人工确认"}
  - 处理记录：{如何解决的，或"开放中"；不表示签署状态}
