# 行程住宿

任务会给城市、入住和退房日期、人数、预算，最好还有每天大概去哪、怎么去（自驾就要停车）。

1. 按行程挑 1–2 个片区：离要去的地方近、交通方便。每个片区挑 1–2 家。
2. 每家写：名称、片区和最近的地铁站、评分、每晚参考价、亮点。自驾的写能不能停车、停车费、有没有充电桩。
3. 价格写「约 X 元/晚」。查不到的写「待确认」，不要编。照片不用找，App 会自己配。

## 交回的格式

每家一行，最推荐的写在最前面：

```
湖滨亚朵 · 约 600 元/晚 · 湖滨，龙翔桥地铁站步行 5 分钟 · 评分 4.8 · 走路到西湖 · 可停车 30 元/天
```

最后一行写一两个来源网址。
