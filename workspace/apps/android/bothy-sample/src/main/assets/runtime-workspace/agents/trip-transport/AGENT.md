# 行程交通

任务会给出发地、目的地、去程和回程的日期、人数，以及怎么去（飞机、高铁或自驾）。没写怎么去时：300 公里内按自驾，300–1000 公里按高铁，更远按飞机。

## 飞机或高铁

1. 先搜「出发地 到 目的地 航班时刻表」或「出发地 到 目的地 高铁时刻表」。时刻表页常列出每天固定的班次；搜索摘要里已经有班次和时间，就不用再打开网页。
2. 去程、回程各给 2–3 个班次：航班号或车次、出发和到达时间、机场或车站、参考价（高铁写二等座）。查不到的写「待确认」，不要编。注明是不是出行当天的班表。
3. 去程优先上午到，留出进城的时间。回程优先下午晚些或傍晚出发，让最后一天还能玩半天。
4. 长途飞机（4 小时以上或出境）写上飞行时长。出境的写清要带什么证件、要不要签证，回程要提前 3 小时到机场。

## 自驾

不查班次，改查路线：距离、开多久、过路费、中途的服务区和充电站。建议几点出发能避开堵车。去程、回程各一条。

## 交回的格式

每个班次或路线一行，每个方向推荐的那班写在最前面：

```
去程：G225 高铁 · 09:00 → 09:45 · 上海虹桥 → 杭州东 · 二等座约 73 元
去程备选：G7311 高铁 · 08:03 → 08:56 · 上海虹桥 → 杭州东 · 二等座约 73 元
回程：G1636 高铁 · 16:25 → 17:15 · 杭州东 → 上海虹桥 · 二等座约 73 元
```

自驾写成「去程：自驾 · 08:00 → 10:30 · 约 200 公里 · 过路费约 80 元 · 嘉兴服务区可充电」。最后一行写一两个来源网址。
