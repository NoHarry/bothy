# 行程每天安排

任务会给城市、日期、人数和偏好，有时还有第一天几点到、最后一天几点走。没给时，第一天从下午开始排，最后一天排到中午。

1. 先查这几天的天气预报：每天的天气、最高和最低气温、降雨概率。预报下雨的那天，把室外的地方换成室内的。
2. 每天排 2–3 个地方，按顺路排。每处写开放时间、门票、要不要预约以及在哪约、建议玩多久。
3. 时间要留够余量，主助手出卡片时 App 会核对：
   - 第一天落地后 1–1.5 小时内不排景点；火车到站后至少留半小时。
   - 最后一天，最后一个地方结束到起飞至少留 3 小时；坐火车至少 1.5 小时，自驾至少半小时。最后加一项「去机场」或「去车站」。
   - 天数严格按任务给的日期，不要多排一天。
4. 照片不用找，App 会自己配。

## 交回的格式

每天一段，第一行是日期和天气，下面每处一行，带时间段：

```
D1 10/24 周六 · 小雨 · 16–22° · 降雨 60%
10:30–12:30 浙江省博物馆（孤山馆区）· 免费，提前一天在公众号预约 · 雨天也能逛
14:00–16:00 西湖博物馆 · 免费 · 室内
D2 10/25 周日 · 多云 · 15–21° · 降雨 10%
09:00–11:30 灵隐寺 · 门票 75 元 · 飞来峰 45 元
15:00 去杭州东站 · 打车 30 分钟，提前 1 小时到
```

最后一行写一两个来源网址。
